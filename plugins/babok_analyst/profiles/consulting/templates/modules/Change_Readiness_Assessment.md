# Change Readiness Assessment — Module

Use in Stage 4 (to shape the change plan) and Stage 5 (to register adoption risk).
Score **per stakeholder group** from Stage 1, never for the organisation as a whole.

---

## ADKAR scoring (1 = absent, 5 = fully present)

| Stakeholder group | Awareness | Desire | Knowledge | Ability | Reinforcement | Weakest element | Readiness |
|-------------------|-----------|--------|-----------|---------|---------------|-----------------|-----------|
| | | | | | | | H / M / L |

Readiness: **H** if weakest ≥ 4 · **M** if weakest = 3 · **L** if weakest ≤ 2.
The intervention for a group targets its *weakest* element first — training
(Knowledge) is wasted where Desire is missing.

## Readiness factors

| Factor | Indicator | Observed | Source |
|--------|-----------|----------|--------|
| Sponsor visibility | Sponsor communicates directly to affected staff at least monthly | | |
| Middle-management alignment | Managers can restate the case for change; change is in their objectives | | |
| Change saturation | ≤ 2–3 concurrent initiatives per team | | |
| Track record | Last comparable initiative delivered / stalled / reversed | | |
| Capacity | Time protected for the change vs. business as usual | | |

## Output into Stage 5 risk register

Every group with Readiness **L** in a high-power quadrant becomes an Adoption risk
rated at least High, with the group's manager as owner.
