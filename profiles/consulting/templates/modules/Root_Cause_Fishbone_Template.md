# Root Cause Analysis — Fishbone & 5-Whys Module

Use in Stage 2 for every finding rated High impact.

---

## 5-Whys

**Finding F-NNN — [symptom]**

| Level | Why? | Answer | Evidence |
|-------|------|--------|----------|
| 1 | Why does the symptom occur? | | |
| 2 | Why does that happen? | | |
| 3 | Why does that happen? | | |
| 4 | Why does that happen? | | |
| 5 | Why does that happen? | **RC-NNN: root cause statement** | |

Stop earlier than five if the answer is already something the organisation controls
and can change; continue past five if the answer is still a symptom.

## Rules

- One root cause should explain several findings; if every finding has its own root
  cause, the analysis has stopped too early.
- Confidence reflects the evidence, not conviction: High = measured data, Medium =
  triangulated interviews, Low = single source.
