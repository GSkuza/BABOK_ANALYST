ends; it must be usable without the consultant.

## Rules

- Every benefit traces to one KPI from Stage 1 and one root cause / value lever from Stage 2.
- Baseline and target use the same unit and measurement method.
- Each benefit has a **lead indicator** visible within 90 days, so realisation can be
  steered before the lag KPI moves.
- Owner is a named client employee with authority over the process the benefit sits in.
